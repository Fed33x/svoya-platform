# СВОЯ • Игровой вечер

Самостоятельно размещаемая платформа для «Своей игры» и «Угадай мелодию»: мобильные кнопки, пульт ведущего, сервер в Docker и нативный клиент Android TV.

## Быстрый запуск на сервере

Требуются Docker Engine / Docker Desktop и Docker Compose v2. Первая сборка загружает Node.js и npm-зависимости из интернета; после сборки игра работает в локальной сети без внешних сервисов.

```bash
unzip svoya-platform.zip
cd svoya-platform
sh scripts/setup.sh
nano .env
docker compose up -d --build
```

`setup.sh` создаёт случайные пароль ведущего и ключ телевизора, записывает их в `.env` и показывает в терминале. Существующий `.env` не перезаписывается.

В `.env` укажите адрес, который открывается с телефонов и телевизора:

```dotenv
PUBLIC_URL=http://192.168.1.100:3000
```

Замените IP на адрес своего сервера. Для публичного HTTPS через reverse proxy поставьте `COOKIE_SECURE=true`. Для локального HTTP оставьте `false`. Смена `PUBLIC_URL` требует `docker compose up -d`.

| Куда                      | Адрес                               |
| ------------------------- | ----------------------------------- |
| Игроки                    | `http://IP-СЕРВЕРА:3000/`           |
| Ведущий                   | `http://IP-СЕРВЕРА:3000/admin`      |
| Запасной браузерный экран | `http://IP-СЕРВЕРА:3000/screen`     |
| Проверка сервера          | `http://IP-СЕРВЕРА:3000/api/health` |

Пароль ведущего — `ADMIN_PASSWORD` из `.env`. Ключ ТВ — `TV_KEY`; он также отображается в админке → «Комната». Одновременно подключается один общий экран: APK **или** браузерный экран.

## Android TV

Установите `svoya-tv.apk` из комплекта на Android TV / Google TV (Android 6.0+). Это debug-сборка для установки вручную, не приложение из Google Play.

1. Откройте приложение «СВОЯ • Игровой вечер».
2. Укажите полный адрес сервера, например `http://192.168.1.100:3000`.
3. Введите `TV_KEY` из `.env` или из админки.
4. Нажмите «Подключить экран».
5. Ведущий управляет игрой с ноутбука. «Назад» на пульте возвращает к настройкам подключения.

Если ADB уже настроен:

```bash
adb install -r svoya-tv.apk
```

ТВ-клиент использует Kotlin, нативные Android Views и Media3 ExoPlayer. Compose не потребовался: интерфейс без сложной навигации сделан на стандартных элементах Android, чтобы сократить зависимости. Медиа загружается в локальный кеш перед открытием кнопок, музыка обрезается по границам фрагмента. Кеш ограничен примерно 600 МБ плюс текущий файл.

Совместимость воспроизведения и видимость интерфейса нужно проверить на конкретной модели телевизора. Поддержка отдельных кодеков зависит от устройства; для музыки предпочтителен обычный MP3, для видео — MP4 с H.264/AAC.

### Сборка APK из исходников

Нужны JDK 17, Android SDK Platform 35, Build Tools 35.0.0. Откройте `android/` в Android Studio либо:

```bash
cd android
# В local.properties укажите sdk.dir=/полный/путь/к/Android/Sdk
./gradlew :app:assembleDebug
```

Результат: `android/app/build/outputs/apk/debug/app-debug.apk`. Debug-ключ генерируется на машине сборки; APK, собранный на другой машине, может потребовать удаления прежней установки из-за другой подписи. Для постоянных обновлений заведите свой release-keystore.

## Первый игровой вечер

1. Войдите в `/admin`.
2. Откройте «Редактор». В комплекте 20 демонстрационных вопросов; замените их на свои. Музыкальных треков в пакете нет.
3. Добавьте песни: правильный ответ, файл, точку начала и ступени длительности/баллов. Пример: 1 / 3 / 5 / 10 / 20 секунд за 500 / 400 / 300 / 200 / 100 баллов.
4. Подключите ТВ. На экране ожидания появится QR-код входа. Для APK QR использует адрес сервера из его настроек; в браузерном экране адрес для QR задаётся при входе.
5. На телефонах выбирают одну из четырёх заранее заданных команд. Каждую команду одновременно занимает один телефон.
6. Нажмите «Начать игру». Откройте вопрос, дождитесь статуса «Экран готов», затем нажмите «Открыть кнопки».
7. Первый игрок отвечает вслух. Нажмите «Верно» или «Неверно».
8. После ответа — «К игровому полю». Для второй игры переключите режим: игроки остаются, счёт ведётся отдельно.

Для браузерного экрана разрешите звук в браузере. Автозапуск аудио может блокироваться браузером: в этом случае сервер ставит игру на паузу. Основной музыкальный клиент — APK.

## Реализованные правила

### Своя игра

- Правильный ответ: плюс стоимость вопроса; ошибочный: минус стоимость (штраф отключается в настройках).
- После ошибки ведущий открывает кнопки остальным. Ошибившийся больше не отвечает на этот вопрос.
- Следующий вопрос выбирает правильно ответивший. Ведущий нажимает выбранную ячейку в админке.
- По истечении таймера устного ответа сервер применяет ошибочный ответ. По истечении времени на кнопку закрывает кнопки без штрафа всем.
- Фото / видео можно прикрепить к вопросу. Видео запускается при открытии кнопок и останавливается при первом ответе / паузе.

### Угадай мелодию

- Мелодия идёт по одной непрерывной шкале: каждый следующий этап продолжает воспроизведение с места остановки, а не запускает песню сначала.
- Границы этапов задаются накопительной длительностью; по мере продвижения награда не растёт.
- Ведущий сам запускает следующий этап.
- Первый принятый ответ останавливает музыку по команде сервера. Задержка остановки зависит от сети.
- Ошибка блокирует игрока на текущем этапе без штрафа. На следующем фрагменте он снова участвует.
- После ошибки «Играть фрагмент» продолжает текущий фрагмент с сохранённой позиции для оставшихся игроков.
- Ведущий может одним нажатием повторить текущий отрезок или запустить всю мелодию сначала; полный перезапуск возвращает первый этап и его стоимость.
- Отдельного аукциона «угадаю с трёх нот» нет: это режим фрагментов разной длины.

### Управление

- Корректировка счёта ±100, отмена последних действий, пауза, раскрытие ответа, завершение игры.
- Отдельная кнопка выводит на ТВ приветственный экран с адресом и QR-кодом, не сбрасывая текущую игру.
- История событий и нажатий (время приёма сервером).
- Закрытие регистрации, удаление отключившихся команд, настройка таймеров, новый вечер со сбросом баллов.
- Редактор вопросов / мелодий, загрузка файлов до 100 МБ, импорт и экспорт пакета JSON.
- Импорт/сохранение пакета открывает ячейки заново, но не сбрасывает баллы. Делайте это до начала игры.

## Сохранение и восстановление

SQLite, сессии ведущего и медиа хранятся в Docker volume `svoya-data` (Compose добавляет префикс проекта к имени volume). Перезапуск контейнера сохраняет данные. `docker compose down` сохраняет volume; `docker compose down -v` **удаляет** его.

Идентификатор команды хранится в localStorage браузера телефона. Обновление страницы / переподключение сохраняет команду. Если ведущий удалил отключившуюся команду из комнаты, на телефоне нужно вернуться к выбору и подключиться заново.

При потере ТВ активный вопрос ставится на паузу. При восстановлении соединения продолжение разрешает ведущий. При перезапуске сервера активный вопрос также восстанавливается на паузе. История отмены хранится только в памяти сервера и исчезает при перезапуске; баллы и журнал сохраняются.

Для резервной копии остановите приложение и сохраните **весь** volume (SQLite вместе с файлами WAL/SHM, если они есть, и каталогом media). Экспорт JSON из админки содержит только пакет с ID медиа, не сами файлы и не результаты.

## Сеть и доступ

- Телефоны, ноутбук и ТВ должны видеть TCP-порт 3000 сервера. Docker — на сервере; APK работает на ТВ отдельно.
- Для наиболее ровных задержек используйте одну Wi-Fi-сеть, сервер и ТВ подключите по Ethernet.
- Побеждает первое допустимое нажатие, **пришедшее на сервер**; абсолютной компенсации сетевой задержки нет.
- Reverse proxy должен пропускать WebSocket Upgrade и сохранять Host. Для загрузки медиа разрешите размер запроса не менее 100 МБ.
- Админка защищена паролем и HttpOnly-cookie, ТВ — отдельным ключом. Игроки не получают ответы заранее, заметки, токены других игроков или ссылки на медиа.
- Не передавайте игрокам ключ ТВ или пароль ведущего. HTTP в локальной сети не шифрует трафик; для доступа через интернет используйте HTTPS.
- Один экземпляр Node.js на один volume. Горизонтальное масштабирование и несколько независимых игровых комнат в этой версии не реализованы.

## Разработка и проверки

Node.js 24:

```bash
npm ci
npm run build
ADMIN_PASSWORD=local-password TV_KEY=local-tv-key npm start
```

Для разработки интерфейса можно отдельно запустить `npx vite --host 0.0.0.0`; API и сокеты проксируются на порт 3000.

```bash
npm test
```

Тесты проверяют игровую логику и реальный HTTP/Socket.IO-сценарий: роли, гонку двух игроков, начисление и отмену очков, отключение ТВ, музыкальные этапы, права на медиа и восстановление после перезапуска. Интеграционный тест использует локальный порт 3021 и временную БД.

## Объём первой версии

Готова основа двух игр с ручной оценкой устных ответов ведущим. Не включены «кот в мешке», аукционы, скрытые ставки в финале, автоматическое распознавание речи, объединённый зачёт вечера и несколько комнат одновременно.
